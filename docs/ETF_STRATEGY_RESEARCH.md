# ETF 策略研究样板（研究专用）

## 目标与边界

把原来的“名单 → 等权”扩展为“截至某日的历史 → 信号、目标权重、现金 → 次交易日开盘执行 → 每日账本”。首期仅做同币种现金 ETF 的离线研究，不接券商、不改 `daily`、不接管任何其他模拟账户、不将研究收益自动变成可发布策略。

本分支基于 PR #5（其又依赖 #4），不包含 #6 工作台。该链尚未合并时，请使用本分支执行以下命令。不要将其描述为 main 已部署。

方法受 [xquant-beginner](https://xingwudao.github.io/xquant-beginner/) 的确定性内核、规格驱动研究与样本外验证思路启发；实现为本项目的独立轻量模块，不复制教材或安装 `open-xquant`。该教材/框架不构成策略盈利证据。

## 可运行的离线实验

```bash
python -m pip install -e '.[dev]'
python examples/etf_strategy/make_demo.py
zk --provider demo --kb /tmp/zhiku-etf-demo research etf \
  --spec examples/etf_strategy/spec.yaml \
  --bars examples/etf_strategy/synthetic_bars.csv \
  --split 2024-06-03 --out /tmp/zhiku-etf-research
```

三个 DEMO 标识与所有价格均为明确虚构数据。工作日序列不是交易所日历。命令真正跑信号、下个输入交易日开盘、成本、整手数、每日 NAV 与对照，输出带内容哈希的不可变 JSON；重复同一输入得到同一路径，不覆盖已存在且内容不符的报告。运行不需要网络、API key 或实时行情。示例只验证工程行为，不能从收益数字推断现实有效性。

`--split` 是样本外的首个输入交易日。两个区间各自从现金起步；样本外可以使用前面的价格作指标预热，但不继承开发区间仓位或收益。参数固定、不搜索最优窗口、不根据样本外成绩修改阈值。样本外被阅读后不再是未见数据；反复试验需另留最终留出集，不能把每次试验当作新的独立验证。

## 接口与对照

- `StrategySpec`：固定标的池、已知日期、单一动量窗口、阈值、选取数量、调仓间隔、风险限额、资金、整手数及成本。未知字段拒绝；规格指纹不随列表顺序漂移。
- `generate_decision(closes, asof, spec)`：只看截至该日的完整窗口。输出 `signals`、`target_weights`、`cash_weight`、调仓频率、缺失原因与输入/规格指纹。负动量默认留现金；参数不是经过优化的最佳值。
- `schedule_decisions`：按给定交易日行计数，以区间第一行锚定。数据不足时输出空目标及原因，不换用另一策略。
- `backtest_targets`：同一执行器消费任意合法目标权重；卖出后按证券代码顺序买入，现金不足按整手截断。这种确定性顺序会产生分配偏差，输出记录该假设。
- 对照为相同合格池、相同调仓周期/现金上限/费用/执行约束的等权再平衡，而非“永不交易的买入持有”。动量只取 top N，等权取全部窗口完整证券，保留二者实际现金比例，不能将超额全归因于选股能力。

复用旧 `summarize_nav` 的指标输出；不修改旧公式回测的既有语义。旧等权引擎允许缺开盘退收盘，本模块故意不沿用这一行为：缺开盘跳过订单并记录拒绝。旧引擎结果与新引擎结果不能混用或声称数值完全等价。

## 输入数据契约

CSV 必须包含 `date,symbol,open,close,tradable,limit_up,limit_down`。每个日期/标的只允许一行，价格是正有限数或缺失；三个掩码必须显式为 0/1。symbol 必须与规格固定池一致。缺标的行不推定可交易。输入行定义交易日历，调用方负责提供真实交易所日历，不把休市日当交易日。

`universe_known_at` 必须早于研究起点，只是声明和防误用检查，不是历史成分证据。实数据需要另外审计当时已上市、未存活证券、基金终止/合并、池变化等选择偏差。本样板不提供历史 ETF 池发现器。

开收盘必须使用同一一致价格口径。不要混用复权收盘与未复权开盘。首期没有现金分红/拆并份额处理引擎，真实事件跨越的数据必须由独立数据流程规范化并验算；即便规范化也应说明回测是价格收益还是总收益。首期不支持多币种、税种差异、不同交易所的结算规则、分钟级交易、动态成分或复杂衍生品。

## 执行与会计约束

- 收盘信号只能在严格更晚的下一个输入交易日开盘执行；末日信号没有下一日则记录不成交。
- 不以收盘替代缺失开盘；涨停不能增加持仓，跌停不能减少持仓，暂停不能交易。传入掩码中的缺失值按禁止交易处理。
- 每日保存实际数量、现金与收盘 NAV，不用不漂移的目标权重冒充持仓。现金不能为负；卖买双边都计成本与滑点。
- 同一会话最多一次目标执行，卖出在买入前，防止新购证券当日卖出。仅适用于已声明同币种现金 ETF 模型，不能直接套用到美股现金交收。
- 空目标会尝试清仓，卖不出的持仓继续估值。缺持仓收盘价格使整个研究失败，而不是以零价或旧价制造完整净值。
- 研究仅用日线开盘代理，不保证现实成交或交易容量，未建市场冲击模型。
- 指标的初始现金基线放在首个输入会话之前一日（只用于计算），避免隐藏首日交易损益；公开逐日账本仍严格对应输入会话。回撤为负值，复用旧指标口径。

## 研究验收与后续发布

所有输出均 `RESEARCH_ONLY`、`production_eligible=false`、`passed_gate=false`。60 个样本外会话仅是样本长度诊断，不是收益通过标准。本轮没有新建一个能绕过 #5 准入的新发布入口；`daily` 仍只读取既有经过显式发布的公式/模型。

下一阶段应先补真实数据版本和事件账对账、更多时间窗口与市场环境的冻结验证、前瞻模拟观察、完整样本外标准，再设计单独的策略发布 manifest 及同语义 daily 消费。不能将 `sample_sufficient=true` 或单次超额为正理解为已验收。
